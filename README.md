# CareerTalker - Voice-Based AI Career Counselor

A voice-based, country-aware AI Career Counselor chatbot MVP built with Next.js.

## Features

- Voice-to-voice conversation with AI career counselor
- Country-specific career and resume advice
- Conversational information gathering (country, role, experience)
- Push-to-talk recording interface
- Audio playback of AI responses

## Setup

1. Install dependencies:
```bash
npm install
```

2. Create a `.env.local` file with your OpenAI API key:
```
OPENAI_API_KEY=your_api_key_here
```

3. Run the development server:
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Tech Stack

- Next.js 14 (App Router)
- React 18
- OpenAI API (Whisper, GPT-4, TTS)
